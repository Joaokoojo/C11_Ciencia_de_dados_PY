# C11_Ciencia_de_dados_PY
C11 - Ciência de dados com Python

Este repositório contém os trabalhos realizados ao longo do semestre da matéria C11 - Ciência de Dados com Python. O objetivo é aprender a criar, manipular e analisar dados através do Python.

O repositório está dividido em duas pastas, cada uma com um respectivo projeto diferente. Dentro de cada pasta, possui um slide explicando brevemente o assunto e as perguntas levantadas sobre o tema e um arquivo IPYNB com todas as análises feitas e seus respectivos gráficos. Os temas são:
1 - Global AI Layoffs & Job Market (2020-Present) -- PROJETO 1
2 - TikTok & Instagram Addiction Dataset (2015–2060) --PROJETO 2
